# Мой первый DevOps-проект: Изучение Git и Linux в Ubuntu

Практический репозиторий, созданный в процессе освоения базовых инструментов DevOps-инженера. Здесь зафиксированы этапы настройки локального окружения в Ubuntu Linux, связки с облаком GitHub и решения сложных конфликтов управления версиями.

## 🚀 Чему я научился в этом проекте

### 1. Работа с терминалом Linux (Ubuntu)
- Создание структуры проекта через консоль с помощью команд `mkdir` и `touch`.
- Управление процессами в системе (`sleep`, `ps aux`, отправка в фон через `Ctrl + Z` и жесткое уничтожение зависших задач через `kill -9`).
- Навигация и телепортация по директориям (`cd`, `cd ..`).

### 2. Локальный контроль версий (Git)
- Инициализация репозитория и отслеживание изменений файлов (`git init`, `git status`).
- Пошаговое создание контрольных точек (сохранений) проекта (`git add`, `git commit`).
- Анализ истории проекта с помощью расширения **Git Graph** и консольной команды `git log --oneline`.

### 3. Работа с ветками и разрешение конфликтов (Advanced Git)
- Создание изолированных веток для безопасных экспериментов с кодом (`git branch`).
- **Разрешение конфликтов слияния (Merge Conflict):** Успешно смоделирован и решен вручную конфликт, когда код в ветке `main` и экспериментальной ветке столкнулся в одной строчке файла `index.html`.
- Безопасное удаление отработавших веток после их успешного слияния.

### 4. Интеграция с облаком GitHub
- Связывание локального репозитория в виртуальной машине Ubuntu с удаленным сервером GitHub.
- Настройка ручной безопасной авторизации через **Personal Access Token (Токен классического доступа)** для выполнения команд `git push`.

## 📦 Структура репозитория
* `index.html` — базовый HTML-файл, на котором тестировалась магия перемещения во времени и конфликты слияния.
* `README.md` — этот файл с документацией и шпаргалкой.

## 🛠️ Окружение
- **ОС:** Ubuntu Linux (последняя LTS-версия на виртуальной машине)
- **Редактор:** VS Code (с расширениями GitLens и Git Graph)
- **Платформа:** GitHub (Аккаунт: `danikgulenkovv-ai`)
